# לינקים לתשלום במורנינג

עודכן 12.10.2026, אחרי פרה-מורטם. החלטות: D105, D106 ב-DECISIONS.md.

## במשפט אחד

בדלפק `/admin/sales`, בתוך המחשבון של כל שירות, יש אזור "לינק לתשלום" שמכין ללקוח הודעת וואטסאפ עם הסכום ולינק של מורנינג. הלקוח משלם באשראי או bit, ומורנינג שולח לו חשבונית לבד.

## מה קיים היום

| לינק | איפה | הערה |
|---|---|---|
| הקלטת שיר, קבוע | https://mrng.to/QCmBPN0A7u | 590 ₪ |
| סכום פתוח | https://mrng.to/gCVaKtIwtG | 5 סכומים לבחירה: 590, 885, 1,770, 3,304, 5,310. עד 3 תשלומים |
| מקדמה | אין | לא חובה. רק אם יקיר רוצה (D6) |

כל שירות בלי לינק קבוע משתמש בלינק הסכום הפתוח, וההודעה אומרת ללקוח את הסכום המדויק. כשהסכום ברשימה כתוב "בוחרים", אחרת "מקלידים".

## איך הדלפק מחליט

- **לינק קבוע** רק כשהלקוח קונה את השירות עצמו, בלי שדרוגים ומשתתפים, וכשהמחיר בלינק שווה למחיר בקטלוג היום. אחרת לינק הסכום הפתוח.
- **מחיר שזז בקטלוג**: הדלפק מפסיק לשלוח את הלינק הקבוע הישן לבד ועובר לסכום הפתוח, עד שהלינק במורנינג מתעדכן. `audit:pricing` מזכיר את זה.
- **הכפתורים נעולים** עד שמעתיקים את ההודעה או "רק לוודא": הלינק הוא ההודעה השלישית.
- **מנוי חודשי, יומי או לפרק**: ההודעה כותבת "לחודש", "ליום" או "לפרק" אחרי הסכום.

## איך מוסיפים או משנים לינק (בלי טרמינל מצד יקיר)

1. יוצרים את הלינק במורנינג: תשלומים, לינקים לתשלום, פלוס.
2. מעתיקים את הקישור ושולחים לסוכן עם שם השירות.
3. הסוכן מריץ, בודק ודוחף:

```bash
npm run morning:link -- --id <מזהה> --url <לינק>
npm run morning:link -- --check
npm run morning:checklist
```

ואז מפרסם מחדש את עמוד המצב: https://claude.ai/artifact/GV87UNb2JaPi3fiEZh1gPP

**שינוי מחיר:** קודם עורכים את הלינק במורנינג לסכום החדש (הקישור לא משתנה), ואז הסוכן מריץ `npm run morning:link -- --id <מזהה> --price <סכום>`.

**שינוי בסכומים לבחירה בלינק הפתוח:** אחרי העריכה במורנינג, `npm run morning:link -- --presets 590,885,1770,3304,5310`.

## איך יודעים אם זה עובד

- פעם בשבוע, בשורת הספירה השבועית בדלפק, יש שדה "מהן שולמו בלינק". המספר מגיע ממורנינג: לינקים לתשלום, צפייה בעסקאות.
- היעד לחודש הראשון: 10 תשלומים בלינק (D106).

## פקודות

| פקודה | מה |
|---|---|
| `npm run morning:link -- --list` | מה שמור ובאיזה מצב |
| `npm run morning:link -- --check` | בדיקה, רצה גם ב-audit:pricing |
| `npm run morning:link -- --bank "..."` | שורת "או בהעברה" בהודעה. ריק מסיר |
| `npm run morning:link -- --remove <מזהה>` | אחרי הקפאת לינק במורנינג |
| `npm run morning:sheet` | מה להקליד במורנינג ללינק קבוע ל-8 הנפוצים |
| `npm run morning:checklist` | בונה מחדש את עמוד המצב |
