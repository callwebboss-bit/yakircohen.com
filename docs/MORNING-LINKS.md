## מה יש בדלפק היום

לכל כרטיס אזור "לינק לתשלום":
- הכפתורים אפורים עד שהעתקת "הודעה" או "רק לוודא" באותו כרטיס (הלינק הוא ההודעה השלישית).
- **העתק הודעה עם לינק** (קצרה): `לתשלום על {שירות}, {סכום} כולל מע״מ: {לינק}` + "אחרי התשלום החשבונית מגיעה למייל אוטומטית."
- **עם הפירוט**: + "כולל a, b, c. לא כולל d, e." מהקטלוג, עד 350 תווים, הלינק תמיד נשאר.
- **או בהעברה**: מופיע רק אחרי `npm run morning:link -- --bank "הטקסט שלך"` (בלי מספר חשבון בקוד; מה שתכתוב זה מה שיישלח).
- **רק הלינק**, **התשלום לא עבר?** ("קורה לפעמים. נסו שוב בלינק הזה, או בהעברה, ואני מאשר מיד").
- **מקדמה (רק באישור יקיר)**: קישור קטן שפותח את "העתק לינק מקדמה 200 ₪". ההודעה: "מקדמה של 200 ₪ לשמירת התאריך, היתרה לפי ההצעה".
- **שדות ללינק קבוע במורנינג**: מה להקליד כדי ליצור לינק לשירות הזה. התיאור: "{שירות}. התנאים: yakircohen.com/whats-included".

## שינוי מחיר (סדר הפוך)

קודם עורכים את הלינק במורנינג לסכום החדש (ה-URL נשאר, מדריך "עריכת לינק לתשלום"), ואז מעלים את המחיר בקטלוג ומריצים `npm run morning:link -- --id <מזהה> --price <הסכום>`. ככה אין חלון שבו לקוח משלם מחיר ישן. `audit:pricing` נכשל אם שכחת.

## מה עוד לא נבנה (תלוי בשלב 0)

- מסלול B/C: דפי תשלום לעסקה מתוך הדלפק (`POST /payments/form`) דורשים מפתח בשרת. אם יקיר לא רוצה מפתח ב-Vercel, נשארים עם לינקים קבועים + סכום פתוח.
- `morning:status`: HEAD על כל URL, מחיר שזז מול הקטלוג, פעם ביום לוואטסאפ של יקיר (בלי API, רק הלינקים הציבוריים).
- webhook "תשלום התקבל" -> הליד מסומן "שולם" (D22) + וואטסאפ ליקיר עם סכום וקוד פנייה בלבד. דורש שה-webhook של מורנינג ישלח `custom`/הערה (שלב 0 עונה).
- סנכרון פריטים ממורנינג חזרה: לא בריפו. Cursor מריץ שוב את ההנחיה עם `morning-items.json` מעודכן אחרי שינוי מחיר.

## כללים

- הסכום בלינק תמיד כולל מע״מ, גם לעסקים. אין מספרים בהודעות שלא מהכרטיס. עד 350 תווים, בלי סימני קריאה (audit:ai-tells).
- הקובץ `lib/data/morning-links.json` מכיל רק URL-ים ציבוריים של מורנינג (greeninvoice.co.il, morning.co, grow.co.il, meshulam.co.il), בלי מפתחות.
- הלינק ללקוחות חדשים ורחוקים (אולפן נייד, מתנות, עסקים). לא דוחפים העברה בנקאית לאשראי: עמלה 1.4% + 1.2 ₪ לעסקה (Best), bit +0.3% (greeninvoice.co.il/payment-links, 11.10.2026).
- מורנינג: אחרי תשלום בלינק המסמך (חשבונית מס-קבלה או קבלה) מופק ונשלח ללקוח במייל אוטומטית. לינקים לתשלום דורשים Best ומעלה וסליקה פעילה (יש).
