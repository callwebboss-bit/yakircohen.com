# לינקים לתשלום במורנינג: איך זה עובד ואיך מתפעלים

עודכן 11.10.2026. החלטת הבעלים (11.10): הלינק לתשלום מופיע רק בדלפק `/admin/sales`, לא בעמודי האתר. סוגרים בוואטסאפ כרגיל, ובמקום "תשלחו העברה" שולחים לינק שהלקוח משלם בו בקליק, באשראי או bit, והחשבונית יוצאת ממורנינג לבד.

## מה יש

שלוש שכבות של לינקים, כולן נוצרות ידנית במורנינג (תשלומים, לינקים לתשלום) ונשמרות ב-`lib/data/morning-links.json`:

| לינק | מה הוא | מתי משתמשים |
|---|---|---|
| מקדמה | 200 ₪ לשמירת תאריך (החלטה D6) | כשהלקוח רוצה לשריין תאריך לפני התשלום המלא |
| סכום פתוח | הלקוח בוחר או מקליד סכום; עם "סכומים קבועים לבחירה" לנקודות המחיר הנפוצות | כל שירות שאין לו לינק קבוע, קומבו, משתתפים נוספים, "החל מ" |
| קבוע לשירות | שם ומחיר קבועים, הלקוח רק משלם | שמונת הנפוצים, ואחריהם כל שירות שחוזר על עצמו |

בדלפק, לכל כרטיס יש אזור "לינק לתשלום" עם ההודעה המוכנה ללקוח (סכום כולל מע״מ + הלינק), "העתק רק את הלינק", "העתק לינק מקדמה", וכשאין לינק קבוע, "שדות ללינק קבוע במורנינג" שמעתיק בדיוק מה להקליד שם.

## הקמה ראשונה (פעם אחת, כ-40 דקות)

דרישות: מסלול Best ומעלה ותוסף סליקה פעיל (יש). מדריך מורנינג: greeninvoice.co.il/help-center/create-payment-link

1. `npm run morning:sheet` כותב את `docs/morning-links-sheet.md` עם כל מה שצריך להקליד.
2. במורנינג: תשלומים, לינקים לתשלום, פלוס, "לינק לעסקה רגילה" למקדמה. מעתיקים את ה-URL:
   `npm run morning:link -- --id deposit --url <הלינק>`
3. פלוס, "לינק בסכום פתוח", מפעילים "הגדרת סכומים קבועים לבחירה" עם הסכומים מהגיליון:
   `npm run morning:link -- --id open --url <הלינק>`
4. לכל אחד משמונת הנפוצים, "לינק לעסקה רגילה" עם השדות מהגיליון:
   `npm run morning:link -- --id song_recording --url <הלינק>`
5. `npm run morning:link -- --check` ירוק, ואז commit ו-push. הדלפק מציג את הלינקים אחרי הפריסה.

## שוטף

- **שירות חדש שחוזר על עצמו:** בדלפק, "שדות ללינק קבוע במורנינג", יוצרים, שומרים עם `morning:link --id --url`.
- **מחיר זז בקטלוג:** `audit:pricing` (שרץ ב-verify:ci) נכשל עם "המחיר בקטלוג X, הלינק נוצר על Y". עורכים את הלינק במורנינג לסכום החדש (ה-URL נשאר, מדריך "עריכת לינק לתשלום") ומריצים `npm run morning:link -- --id <מזהה> --price <הסכום החדש>`.
- **שירות ירד מהקטלוג:** מקפיאים את הלינק במורנינג ומריצים `npm run morning:link -- --remove <מזהה>`.
- **לראות מה שמור:** `npm run morning:link -- --list`.

## כללים

- הסכום בלינק הוא תמיד כולל מע״מ, כי זה מה שנגבה. גם לשירותים לעסקים.
- אין מספרים בהודעות שלא באים מהכרטיס. ההודעה עד 350 תווים, בלי סימני קריאה (audit:ai-tells).
- הקובץ מכיל רק URL-ים ציבוריים של מורנינג (`isMorningUrl`), בלי מפתחות. אין כאן API: החלטה D29 מכניסה את ה-API של מורנינג רק אחרי PRIVACY-AUDIT.
- קומבו, משתתפים נוספים והנחה עוברים דרך הלינק בסכום הפתוח, עם הסכום בהודעה. הלינק הדינמי מה-API (`POST /payments/form`) מתוכנן לשלב הבא, אחרי D29.

## מה מורנינג עושה אחרי התשלום

לפי המדריכים של מורנינג: אחרי תשלום בלינק, המסמך (חשבונית מס-קבלה או קבלה, לפי סוג התשלום) מופק ונשלח ללקוח במייל אוטומטית. העמלה במסלול Best: 1.4% + 1.2 ₪ לעסקה, bit בתוספת 0.3% (greeninvoice.co.il/payment-links, 11.10.2026).
