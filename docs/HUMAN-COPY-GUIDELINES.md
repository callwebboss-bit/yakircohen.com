# הנחיית כתיבה אנושית - ניקוי סימני מים רובוטיים

**מטרה:** כל הקופי באתר צריך להיראות ולהישמע **אנושי**, לא "נכתב ע"י AI". תווים
טיפוגרפיים מסוימים הם חתימה מובהקת של כתיבת מכונה ולא נהוגים בעברית אנושית - הם
נמחקים ומוחלפים בגרסה האנושית. אכיפה אוטומטית: `npm run audit:ai-tells`.

## תווים אסורים והחלפתם

| אסור | שם | להחליף ל |
|---|---|---|
| `—` | מקף ארוך (em-dash, U+2014) | מקף רגיל עם רווחים: ` - ` |
| `–` | מקף בינוני (en-dash, U+2013) | מקף רגיל: `-` |
| `…` | שלוש נקודות כתו יחיד (ellipsis, U+2026) | שלוש נקודות רגילות: `...` |
| `"` `"` | מרכאות כפולות מסולסלות/מלוכסנות (U+201C/D) | מרכאות ישרות `"` (ב-JSX: `&quot;`) או גרשיים `״` |
| `'` `'` | גרש/מרכאה בודדת מסולסלת (U+2018/9) | גרש ישר `'` או `׳` |
| `&mdash;` | ישות em-dash | ` - ` |
| `&ndash;` | ישות en-dash | `-` |
| `&ldquo;` `&rdquo;` | ישויות מרכאות מסולסלות | `&quot;` |
| `&lsquo;` `&rsquo;` | ישויות גרש מסולסל | `&#39;` |
| `&hellip;` | ישות שלוש נקודות | `...` |
| תווים בלתי-נראים | ZWSP/ZWNJ, BOM אמצע-קובץ | להסיר |

## מה **כן** מותר (לא לגעת)

- **גרשיים עבריים `״` (U+05F4)** - פיסוק עברי תקין (למשל `מע״מ`, `ת"י`). לא סימן AI.
- **גרש עברי `׳` (U+05F3)** - תקין.
- **ZWJ (U+200D) בתוך אמוג'י** - חלק לגיטימי מרצף אמוג'י (למשל `👨‍👩‍👧‍👦`).
- **מרכאות ישרות `"` `'`** - נייטרליות ואנושיות.

## סימני קריאה

**אין סימני קריאה (`!`) בקופי** - הקול המותגי יבש ועובדתי. ראו `scripts/audit-no-exclamation.mjs`.

## חתימות כתיבת AI בניסוח (להימנע, שיפוט אנושי)

מעבר לטיפוגרפיה, להימנע מדפוסים שמריחים מכונה:

- **חיבורים פורמליים מוגזמים:** "יתרה מזאת", "בנוסף לכך", "כמו כן", "לסיכום" בכל פסקה.
- **גידור יתר / hedging:** "ייתכן ש", "באופן כללי", "לרוב" כשאפשר להיות ישיר.
- **מבנה חוזר וסימטרי מדי:** כל פסקה באותו אורך/תבנית.
- **מילוי גנרי:** "בעולם של היום", "לא סוד ש", "כידוע".
- **סופרלטיבים ריקים:** "המקצועי ביותר", "האיכותי ביותר" בלי גיבוי.

עדיף: משפטים קצרים, ישירים, עם פרטים קונקרטיים (מחיר, זמן, מה בדיוק מקבלים).

## אכיפה ותשתית

- **אודיט:** `npm run audit:ai-tells` - נכשל אם נמצא תו אסור ב-`lib/`, `components/`, `app/`.
- **מנרמל ריצה:** `lib/mashup-copy-humanize.ts` כבר ממיר מקפים ותווים חריגים בקלט משתמש בזמן ריצה (מוחרג מהאודיט - מכיל מקפים בכוונה בתוך regex).
- **קבצים אוטומטיים:** `*.generated.*` מוחרגים; אם מקור הייבוא (יוטיוב וכו') מכניס תווים אסורים - לתקן ב-override, לא בקובץ המיוצר.
- **BOM:** תווי BOM בתחילת קבצים הם שריד עריכה מ-Windows/Dropbox (ר' משימת נרמול EOL/`.gitattributes`), בלתי-נראים ולא משפיעים על הרינדור - מטופלים בנפרד מהאודיט הזה.
